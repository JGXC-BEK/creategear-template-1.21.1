## Create:gear
**Practice project**  
An addon mod for Create  
on NeoForge 1.21.1  
that adds a helical gear and its related mechanics.  
Additionally, diagonal connections of large gears have been disabled.  
Write with ai  
Create：[Creators-of-Create/Create: [NeoForge Mod] Building Tools and Aesthetic Technology](https://github.com/Creators-of-Create/Create)
